# NavCore SDK 1.0.9 API Reference

Welcome to the comprehensive API reference for the NavCore SDK. Every public class, interface, type alias, constant, and utility function exported by the five public 1.0.9 packages is documented in detail.

---

## Package References

| Package | Scope | Reference Document |
|---|---|---|
| **`@ingissa/navcore-core`** | Navigation engine, Kalman filter, snapper, FSMs, route planning, dead reckoning, and built-in directions providers. Subpaths: `.`, `./core`, `./pro`. | [Core API Reference](./navcore-core.md) |
| **`@ingissa/navcore-react-native`** | React Native bindings, context provider (`NavCoreProvider`), and granular state selector hooks (`useNavSelector`, `useNavInstruction`, etc.). | [React Native API Reference](./navcore-react-native.md) |
| **`@ingissa/navcore-simulator`** | Headless GPS simulation engine, noise models, scenario injection, and React Native UI controls. Subpaths: `.`, `./node`, `./react-native`. | [Simulator API Reference](./navcore-simulator.md) |
| **`@ingissa/navcore-mapbox`** | Mapbox Directions API provider adapter with automatic waypoint chunking. | [Mapbox API Reference](./navcore-mapbox.md) |
| **`@ingissa/navcore-types`** | Shared domain interfaces and type definitions used across the ecosystem. | [Types API Reference](./navcore-types.md) |

## Verification & Type Safety

Every signature and default parameter in this API reference has been validated against the built TypeScript definition files (`.d.ts`) generated by `tsup` in version 1.0.9.
